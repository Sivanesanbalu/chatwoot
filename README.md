# Chatwoot Lite (LiveChat Support Platform)

> Modern, lightweight, open-source customer support and live messaging platform built with Next.js, React, and Tailwind CSS. **100% Vercel & Serverless compatible with zero monthly fees and no credit card required.**

---

## ✨ Features

- 💬 **Live Customer Widget**: Floating chat bubble for website visitors to reach out.
- 🎧 **Support Agent Inbox**: Chatwoot-style dashboard to view, filter, assign, and reply to customer inquiries in real time.
- ⚡ **AI Auto-Replies**: Built-in automated assistant answers common queries instantly when agents are away.
- 📋 **Canned Responses**: Pre-written templates for 1-click answers to frequent questions.
- 🌐 **1-Line Embed Code**: Easily embed on WordPress, Shopify, Next.js, or any static HTML site using `<script src="https://your-domain/widget.js"></script>`.
- 🚀 **100% Free Hosting on Vercel**: No credit card needed, runs on serverless edge functions.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Hosting**: Vercel (Edge & Serverless)

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🚀 Deploy to Vercel (Free)

Deploy via the Vercel CLI:
```bash
vercel --prod
```
Or import directly from GitHub on [vercel.com](https://vercel.com).
